# הרכבת הממשלה 2026

אתר קטן שעוקב אחרי הליך הרכבת הממשלה אחרי הבחירות לכנסת ה־26, ויומן (`.ics`) שאפשר להירשם אליו באייפון ובמק. האתר והיומן מתעדכנים לבד.

- **האתר:** https://gabimansoure-coder.github.io/memshala-2026/
- **היומן:** `webcal://gabimansoure-coder.github.io/memshala-2026/calendar.ics`
- **יומן תרחישים (אופציונלי):** `webcal://gabimansoure-coder.github.io/memshala-2026/scenarios.ics`

המועדים לא נכתבים ביד. הם מחושבים מקובץ אחד, [`state.yaml`](state.yaml), לפי חוק־יסוד: הממשלה.

---

## 1. הרשמה ליומן

### באייפון
1. פותחים את האתר ב-Safari ולוחצים **הוספה ליומן**.
2. בחלון שנפתח לוחצים **הרשמה** (Subscribe).
3. בשדה **חשבון** בוחרים **iCloud**, כדי שהיומן יופיע גם במק. לוחצים **הוסף**.

דרך נוספת: **הגדרות ← לוח שנה ← חשבונות ← הוספת חשבון ← אחר ← הוספת לוח שנה מנוי**, ומדביקים את כתובת היומן.

### במק
1. פותחים את **לוח שנה**. בתפריט **קובץ** בוחרים **מנוי חדש ללוח שנה**.
2. מדביקים את הכתובת `webcal://gabimansoure-coder.github.io/memshala-2026/calendar.ics` ולוחצים **הרשמה**.
3. ב**רענון אוטומטי** בוחרים **כל שעה**.
4. **חשוב:** ליד **הסר** מבטלים את הסימון של **התראות**. אחרת, Apple מוחקת את התזכורות שביומן.
5. ב**מיקום** בוחרים **iCloud** ולוחצים **אישור**.

ביומן יש:
- טקסים, השבעות והצבעות אמון, עם שעה.
- מועדי סיום (כמו סוף 28 הימים) כאירועי יום שלם, עם תזכורת ב-9:00 ביום שלפני.
- מועד שלא הוכרז רשמית מסומן בכותרת ב-**(מחושב)**. בתיאור של כל אירוע יש הסבר קצר, הסעיף בחוק וקישור למקור.
- כשאירוע מפסיק להיות רלוונטי (למשל הארכה שלא ניתנה), הוא נמחק מהיומן ברענון הבא.

## 2. עריכה ידנית של `state.yaml`

`state.yaml` הוא מקור האמת. רושמים בו רק **עובדות**: דברים שקרו או שהוכרזו. את המועדים שנגזרים מהן המנוע מחשב לבד.

עריכה ידנית תמיד גוברת: האוטומציה רק **מוסיפה** אירועים חדשים, ולעולם לא משנה או מוחקת אירוע קיים. אם מחקתם אירוע שהאוטומציה הוסיפה, היא זוכרת את זה (בקובץ `data/automation.json`) ולא תוסיף אותו שוב.

### איך עורכים (גם מהטלפון)
1. נכנסים ל-[`state.yaml` בגיטהאב](https://github.com/gabimansoure-coder/memshala-2026/blob/main/state.yaml).
2. לוחצים על סמל העיפרון (**Edit**).
3. מוסיפים אירוע בסוף הרשימה `events:`, עם אותה הזחה כמו האירועים הקיימים (ראו דוגמאות למטה).
4. לוחצים **Commit changes**, ושוב **Commit changes**.
5. תוך 2–3 דקות האתר והיומן מתעדכנים. אם יש שגיאה בקובץ, הריצה נכשלת, האתר הישן נשאר באוויר, ומגיע מייל מגיטהאב.

### שדות של אירוע

| שדה | חובה | הסבר |
|---|---|---|
| `id` | כן | מזהה קבוע באנגלית. לא משנים אותו אחר כך, כי ממנו נגזר ה-UID ביומן. |
| `type` | כן | סוג האירוע (טבלה למטה). |
| `date` | כן | `YYYY-MM-DD`, לפי שעון ישראל. |
| `time` | לא | שעה במירכאות, למשל `"17:00"`. רק אם השעה ידועה. |
| `candidate` | לפי הסוג | שם המועמד, בדיוק כמו בהטלת המנדט. |
| `status` | לא | `official` (ברירת מחדל): הוכרז. `computed`: נגזר או משוער. |
| `source` | מומלץ | קישור למקור. |
| `note` | לא | הערה שתופיע בתיאור. |
| `title` | לא | כותרת אחרת במקום ברירת המחדל. |
| `location` | לא | מקום, למשל `בית הנשיא, ירושלים`. |

### סוגי אירועים

| `type` | מתי | שדות נוספים |
|---|---|---|
| `mandate_assigned` | הנשיא הטיל את המנדט | `candidate`, `party`, `round` (1/2/3, לא חובה), `deadline` (אם הוכרז מועד רשמי) |
| `extension_requested` | המועמד ביקש הארכה | `days` (לא חובה) |
| `extension_granted` | הנשיא העניק הארכה | `days`, `new_deadline` (אם הוכרז) |
| `mandate_returned` | המועמד הודיע שאין בידו להרכיב ממשלה | |
| `period_expired` | התקופה נגמרה בלי הודעה (לא חובה, המנוע מזהה לבד) | |
| `success_notice` | המועמד הודיע לנשיא ולכנסת שהרכיב ממשלה | |
| `knesset_notified` | יו"ר הכנסת הודיע לכנסת | |
| `confidence_vote_scheduled` | נקבע מועד להצבעת האמון | `time` |
| `confidence_vote` | הכנסת הצביעה | `result: passed` או `failed`, `votes_for`, `votes_against` |
| `government_sworn_in` | השבעת הממשלה | `time` |
| `president_no_possibility` | הנשיא הודיע שאין אפשרות להרכיב ממשלה | |
| `majority_request` | 61 ח"כים ביקשו להטיל את המשימה על ח"כ מסוים | `candidate` |
| `president_notice_dissolution` | הנשיא הודיע שלא הורכבה ממשלה | |
| `dissolution_law` | הכנסת חוקקה חוק התפזרות | `election_date` |
| `knesset_opening`, `speaker_elected`, `announcement`, `note` | מידע כללי | |

## 3. הצעות לאישור מהטלפון

שינוי שהאוטומציה זיהתה מוחל לבד רק אם **לפחות 2 קבוצות תקשורת שונות** מדווחות עליו (אתרים באותה בעלות, כמו ynet ו-ynetnews, נספרים כמקור אחד). בנוסף, מנוע הכללים צריך לאשר שהשינוי אפשרי לפי החוק. אחרת, נפתח Pull Request עם השינוי המוצע ורשימת המקורות.

**כדי לקבל התראה ולאשר בלחיצה:**
1. מתקינים את אפליקציית **GitHub** (App Store) ומתחברים.
2. בריפו לוחצים **Watch** ובוחרים **All Activity** (או לפחות Pull requests), כדי לקבל התראות.
3. כשמגיעה הצעה, פותחים אותה, בודקים את המקורות, ולוחצים **Merge pull request** ואז **Confirm merge**. האתר והיומן מתעדכנים תוך דקות.
4. אם ההצעה שגויה, לוחצים **Close pull request**. האוטומציה לא תציע אותה שוב.

## 4. הוספת מפתח Anthropic (לזיהוי חכם של כותרות)

בלי מפתח, הזיהוי נעשה לפי מילות מפתח. עם מפתח, מודל `claude-haiku-5-5` מסווג כל כותרת חדשה לפורמט JSON קבוע. כל כותרת נשלחת פעם אחת בלבד, והתשובה נשמרת במטמון.

**עלות משוערת:** Haiku 5.5 עולה 0.10$ למיליון טוקנים של קלט ו-0.50$ למיליון טוקנים של פלט. זה בערך אגורות בודדות ליום, ופחות מדולר לחודש.

**שלב 1: יצירת מפתח**
1. נכנסים ל-https://console.anthropic.com ומתחברים.
2. **Settings ← Billing**: מוסיפים אמצעי תשלום וקרדיט התחלתי (5$ מספיקים לחודשים).
3. מומלץ: **Settings ← Limits**, ומגדירים תקרת הוצאה חודשית נמוכה (למשל 5$).
4. **Settings ← API Keys ← Create Key**. נותנים לו שם (למשל `memshala-2026`) ומעתיקים את המפתח. הוא מוצג רק פעם אחת.

**שלב 2: שמירת המפתח בגיטהאב** (רק אתם רואים אותו; הוא לא נשמר בקוד)
1. נכנסים ל-https://github.com/gabimansoure-coder/memshala-2026/settings/secrets/actions
2. לוחצים **New repository secret**.
3. ב-**Name** כותבים בדיוק: `ANTHROPIC_API_KEY`
4. ב-**Secret** מדביקים את המפתח ולוחצים **Add secret**.

דרך חלופית מהטרמינל במק (תתבקשו להדביק את המפתח, והוא לא נשמר בהיסטוריה):
```bash
gh secret set ANTHROPIC_API_KEY --repo gabimansoure-coder/memshala-2026
```

מהריצה הבאה, בתחתית האתר יופיע "זיהוי אירועים: Claude Haiku". אם המפתח לא תקין, האוטומציה עוברת למילות מפתח, ובסיכום הריצה ב-Actions מופיעה הערה.

## 7. הנחות ומגבלות
- **תרחישים:** בעץ התרחישים מוצג המועד **המאוחר ביותר** האפשרי בכל מסלול. בפועל, כל צעד יכול לקרות מוקדם יותר.
- **הצבעת אמון:** החוק סופר 7 ימים מההודעה **לכנסת**, לא מההודעה לנשיא. עד שההודעה לכנסת נרשמת, המנוע מניח שהיא נמסרה באותו יום (ב-2021 עברו 5 ימים בין השתיים).
- **פרסום התוצאות:** מועד ערעורי הבחירות מחושב מ-4.11, היום שבו התוצאות הוגשו לנשיא. מועד הפרסום ברשומות טרם אומת.
- **תזמון:** GitHub לא מבטיח ריצה בדיוק כל 30 דקות; עיכוב של כמה דקות הוא רגיל.
- **רענון היומן:** אפליקציית היומן של Apple מחליטה מתי לרענן. במק אפשר לבחור "כל שעה".
- **זיהוי אוטומטי:** הוא יכול לטעות. לכן נדרשים 2 מקורות, המנוע בודק כל שינוי, וכל שינוי נשמר ב-git ואפשר לבטל אותו.
