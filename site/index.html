יומן שמתעדכן לבד

כל המועדים ביומן של האייפון או המק. כשמשהו משתנה, היומן מתעדכן אוטומטית.

הוספה ליומן
איך נרשמים באייפון
  1. פותחים את העמוד הזה באייפון ולוחצים על הוספה ליומן.
  2. בחלון שנפתח לוחצים הרשמה (Subscribe).
  3. בשדה חשבון כדאי לבחור iCloud, כדי שהיומן יופיע גם במק. לוחצים הוסף.

דרך נוספת: הגדרות ← לוח שנה ← חשבונות ← הוספת חשבון ← אחר ← הוספת לוח שנה מנוי, ומדביקים את הכתובת.

איך נרשמים במק
  1. פותחים את אפליקציית לוח שנה, ובתפריט קובץ בוחרים מנוי חדש ללוח שנה.
  2. מדביקים את הכתובת (כפתור "העתקת הכתובת") ולוחצים הרשמה.
  3. ברענון אוטומטי בוחרים כל שעה.
  4. חשוב: ליד הסר מבטלים את הסימון של התראות, אחרת התזכורות יימחקו.
  5. במיקום כדאי לבחור iCloud, ולוחצים אישור.

רוצים לראות גם את מועדי התרחישים החלופיים? יומן תרחישים (נפרד, אופציונלי).
